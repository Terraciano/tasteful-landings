# Repository purpose

This repository contains high-end landing page concepts for high-value industries.

The goal is not generic frontend experimentation.

Each website must demonstrate:
- industry credibility
- strong visual hierarchy
- high-quality frontend implementation
- responsive behavior
- restrained motion
- realistic commercial structure

## Required workflow

Before implementing a page:

1. Read `design/PRINCIPLES.md`.
2. Read the industry's `BRIEF.md`.
3. Read `REFERENCES.md`.
4. Read `COMPONENTS.md`.
5. Inspect the available reference images.
6. Define the page hierarchy before coding.

Never begin from generic frontend assumptions.

## Forbidden defaults

Avoid:
- generic SaaS layouts
- rounded card grids
- excessive gradients
- excessive glassmorphism
- random animations
- black-and-gold luxury clichés
- fake testimonials
- fake statistics
- fake awards
- generic AI marketing copy

If required information is unknown, use neutral placeholders instead of inventing claims.

## Visual review

After implementation, review:
- typography
- spacing
- hierarchy
- alignment
- responsive behavior
- image treatment
- section rhythm
- motion consistency
- industry credibility

A technically correct implementation can still fail visual review.
