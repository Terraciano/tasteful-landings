# <Industry> — Research Playbook

Use after reading the client brief and `RESEARCH_PROTOCOL.md`.

## 1. Resolve the subcategory

List the mutually useful subcategories in this industry.

The agent must choose the primary revenue/conversion motion before researching competitors.

## 2. Direct-competitor query templates

Define 3-6 concrete search templates using:
- subcategory
- geography
- high-intent product/service terms
- local terminology

Examples:
- `<subcategory> <geography>`
- `<service> <geography>`

Avoid generic `luxury <industry>` as the main query.

## 3. Category leaders

List established companies useful for:
- product storytelling
- category terminology
- information architecture
- trust mechanisms

The agent should inspect only the relevant subset.

## 4. Boutique / niche query templates

Define search modifiers that reveal specialist operators, for example:
- boutique
- independent
- specialist
- private
- atelier
- studio
- estate
- principal-led

Only use modifiers that make sense in the industry.

## 5. Insider signals

List terminology, product details, provenance, specifications, process, materials, credentials, or other signals knowledgeable buyers expect.

## 6. Visual questions

List 4-8 questions the research must answer before design.

## 7. Anti-patterns

List common ways generic agencies/LLMs misread this industry.
