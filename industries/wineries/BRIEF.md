# Wineries / Wine Estates — Industry Brief

## Commercial context

Primary use cases:
- premium winery / estate brand
- direct-to-consumer wine sales
- wine club / allocation
- tastings and private visits
- wine tourism / hospitality
- export / importer / distributor inquiries
- estate events when explicitly relevant

Typical purchase decisions combine product quality, provenance, reputation, aesthetics, hospitality, and relationship.

The page should not sell "luxury" in the abstract. It should communicate origin, terroir, craft, confidence, and place.

For Mendoza-oriented brands, geography and landscape are often strategic brand assets, not decorative background.

## Audience

Potential visitors include:
- wine buyers
- collectors
- tourists planning tastings
- importers/distributors
- sommeliers and restaurants
- hospitality guests
- event planners
- local and international buyers

## Primary conversion behavior

Choose based on the business model.

Good examples:
- Reserve a tasting
- Plan your visit
- Explore the wines
- Join the wine club
- Request allocation
- Contact export
- Request trade information
- Book a stay
- Enquire about private events

Avoid generic startup CTAs:
- Get started
- Join now
- Unlock more
- Start free
- Book a demo

## Brand characteristics

Communicate when true:
- origin
- terroir
- restraint
- confidence
- craft
- agricultural specificity
- hospitality
- continuity
- expertise
- relationship to place

Do not default to:
- fake aristocracy
- black-and-gold luxury
- generic rustic nostalgia
- "old world" cosplay
- tech-enabled innovation language
- over-romanticized vineyard copy
- stock-luxury lifestyle

## Design dials

Suggested starting point:
- DESIGN_VARIANCE: 7
- MOTION_INTENSITY: 3
- VISUAL_DENSITY: 4

These are starting values, not immutable tokens.

## Composition

Prefer:
- editorial composition
- landscape-led sections
- product detail with breathing room
- asymmetry
- maps / estate geography when useful
- estate / vineyard / cellar photography
- strong rhythm between open landscape and intimate detail
- tactile image sequencing
- restrained metadata for vintage, varietal, parcel, altitude, aging, etc.

Avoid:
- ecommerce-first card grids as the main identity
- SaaS component language
- endless centered sections
- excessive rounded cards
- fake parchment effects
- decorative vineyard flourishes without purpose
- "premium" signaled only by beige + serif

## Photography / media direction

Primary:
- vineyards
- estate architecture
- Andes / local geography where relevant
- cellar
- barrels / concrete eggs / amphora / production detail when true
- bottles / labels
- harvest
- soil / stone / irrigation / vine detail
- hospitality spaces
- food / table context when relevant

Secondary:
- portraits of winemakers/founders
- archival material
- parcel maps
- fieldwork/process

Avoid:
- anonymous smiling couples toasting
- generic Mediterranean stock if the estate is in Mendoza
- luxury cars
- yacht/jet crossover lifestyle
- excessive staged dinner-table stock

## Typography

Preferred characteristics:
- editorial personality
- strong display typography
- highly readable body copy
- restraint in decorative serif use
- labels/specification typography that supports product detail
- typography that feels rooted in the brand rather than "wine template"

Valid directions may include:
- literary/editorial serif + restrained sans
- contemporary grotesk + characterful display face
- archival-inspired typography when genuine history supports it

Avoid:
- automatic Cormorant/Playfair pairing
- fake handwritten vineyard script
- ornamental typography used merely to signal tradition

## Palette

Palette should come from:
- estate architecture
- soil
- vegetation
- label system
- cellar/material palette
- local light

Useful starting families:
- chalk / limestone / charcoal
- olive / dry grass / warm neutral
- deep burgundy used carefully
- stone / clay / oxide
- mountain blue-grey + earth tones

Avoid defaulting to:
- black + gold
- burgundy + gold
- beige everywhere
- overly saturated wine-red branding

## Information architecture

For a winery homepage:

1. Hero grounded in estate/product/place
2. Wines / collection overview
3. Estate / terroir / geography
4. Craft / winemaking / philosophy
5. Visit / hospitality experience
6. Proof or recognition only if factual
7. Trade / export / club path if commercially important
8. Contact / booking
9. Footer / legal

For a wine product page:

1. Wine identity
2. Vintage / varietal / origin
3. Tasting/profile copy
4. Vineyard / parcel / altitude / soil
5. Winemaking / aging
6. Technical facts
7. Pairing / serving only if useful
8. Purchase / allocation / trade CTA
9. Related wines

For hospitality-led estates:

1. Place / landscape hero
2. Stay / visit proposition
3. Tastings / dining / experiences
4. Estate story
5. Wine connection
6. Gallery
7. Availability / booking CTA

## Copy tone

Use:
- specific
- sensory but restrained
- grounded
- geographically literate
- technically credible
- low-hype
- confident

Prefer:
"Malbec from high-elevation vineyards in Gualtallary"

over:
"An unforgettable expression of timeless luxury"

Prefer concrete nouns:
- vineyard
- parcel
- vintage
- altitude
- soil
- harvest
- aging
- estate
- cellar
- valley

Avoid empty language:
- elevated
- unparalleled
- reimagined
- timeless luxury
- where tradition meets innovation

- wine lodge Mendoza

Local intent matters heavily for tourism.

Product intent matters for wine labels and retail/trade.

Do not keyword-stuff.

## Trust signals

Use only when factual:
- estate history
- vineyard ownership
- appellation / IG / GI / DOC
- altitude
- parcel detail
- certifications
- organic/biodynamic status
- winemaker credentials
- awards
- critic scores
- export markets
- importer relationships
- production volumes
- hospitality credentials
- restaurant/hotel affiliations

For concepts, never invent these.

## Mendoza-specific considerations

Mendoza is not one visual category.

Research the exact zone:
- Luján de Cuyo
- Maipú
- Valle de Uco
- Tupungato
- Tunuyán
- San Carlos
- Gualtallary
- Paraje Altamira
- Agrelo
- Las Compuertas

Do not flatten all Mendoza estates into:
- Andes + Malbec + beige serif

Research:
- estate architecture
- altitude
- soils
- irrigation context
- valley identity
- varietal focus
- hospitality model
- brand age / history
- export vs tourism orientation
