# Wineries / Wine Estates — Optional Human References

Human-curated references are optional.

The default workflow is:
- `RESEARCH_PROTOCOL.md`
- `industries/wineries/RESEARCH_PLAYBOOK.md`

The agent should research current project-specific references itself.

Use this file only when a client or human explicitly wants a specific site considered.

## Pinned reference format

```md
### <Brand / page>

URL:
<url>

Use for:
- ...

Do not copy:
- ...

Reason this reference matters:
- ...
```

## Good reference roles

A pinned reference may be useful for:
- estate storytelling
- wine collection/product presentation
- terroir / map treatment
- architecture
- tourism / tasting booking
- hospitality
- trade/export structure
- typography
- photography
- editorial rhythm

## Prohibited copying

Never reproduce:
- logos
- proprietary copy
- label designs
- trademarked assets
- exact layouts
- proprietary photography

Use patterns, not brand identity.
