# Luxury Construction / Architecture — Research Playbook

## Resolve subcategory
- architecture studio
- custom builder
- design-build
- general contractor
- boutique developer
- interiors + build
- renovation/restoration

## Direct searches
- `custom home builder <geography>`
- `residential architect <geography>`
- `luxury construction <geography>`
- `design build <geography>`
- `high end renovation <geography>`

## Category leaders
Use relevant architecture/build firms in the target market plus strong editorial studios.

## Boutique searches
- `boutique architecture studio <geography>`
- `custom builder <neighborhood>`
- `design studio residential <geography>`
- `artisan builder <geography>`

## Insider signals
- project type
- architect/interior designer
- materials
- scope
- schedule/process
- permits
- procurement
- site constraints
- craftsmanship details

## Visual questions
- Is work or process the primary proof?
- Does the studio need principal personality?
- How much technical/process detail reassures buyers?
- Is materiality visible in photography?
- Should projects be organized by type, location, or story?

## Anti-patterns
- generic contractor iconography
- SaaS sections
- “building dreams” copy
- stock blueprints
- excessive motion over project imagery
