# Luxury Construction / Architecture — Industry Brief

## Commercial context
Use for custom home builders, residential architects, design-build firms, luxury contractors, and boutique developers.

The site sells judgment, craft, process discipline, and built proof.

## Audience
- homeowners
- developers
- family offices
- architects/designers
- owner reps

## Conversions
- Discuss a project
- Request a consultation
- View selected work
- Enquire about a site/project
- Speak with the studio

## Brand characteristics
Prefer:
- architectural literacy
- restraint
- materiality
- process clarity
- craft
- permanence

Avoid:
- generic contractor tropes
- tech-startup innovation copy
- stock hardhat imagery
- black/gold luxury

## Composition
Prefer:
- project photography
- plans/details/materials
- editorial case studies
- whitespace
- selective process content

## Insider signals
- architect/designer
- location
- scope
- completion year
- materials
- procurement/build model
- project type
- awards only if factual
